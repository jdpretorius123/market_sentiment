Market Sentiment & Real-Time Financial Intelligence

This portfolio project uses data from Alpha Vantage and NewsAPI to track the past and current market sentiment of 10 tech stocks:

  • MSFT
  • GOOGL
  • AMZN
  • AAPL
  • DT
  • RMBS
  • AKAM
  • SOUN
  • CLBT
  • INSG

This project is an end-to-end market-sentiment pipeline that ingests financial news from the Alpha Vantage and NewsAPI REST APIs, lands the raw JSON in a Cloudflare R2 data lake, then transforms it through a Python ETL stage that validates every payload with pydantic, scores tone with VADER, and deduplicates records before loading them into a BigQuery warehouse. The warehouse is modeled as a single denormalized "One Big Table" with nested fields, which lets the analytical queries run without joins and keeps loads idempotent via a staging-table MERGE, so re-running a monthly batch never duplicates data. The codebase is organized as an installable src/ Python package with clean separation of concerns (distinct acquisition, ETL, and export stages sitting on shared leaf layers for storage I/O, data-contract schemas, and config) so each phase is independently testable and the dependencies flow in one direction. The final stage aggregates the warehouse into small static JSON files that a D3.js dashboard renders as three interactive visualizations: a streamgraph of sentiment over time, small-multiple radar charts comparing each company's tone profile, and a force-directed graph of ticker-to-topic relationships. The result is a GitHub-Pages-hostable dashboard that turns thousands of raw news articles into a clear, at-a-glance read on how the market is talking about a select set of tech stocks.
